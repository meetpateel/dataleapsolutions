# DataLeap Solutions website

Source for https://dataleapsolution.com, the marketing site for DataLeap, a founder-led software and data consultancy in Sioux Falls, SD.

- Static HTML/CSS/JS built on the BootstrapMade Presento template (paid license).
- Hosted on GitHub Pages. Every push to `main` deploys automatically via `.github/workflows/jekyll-gh-pages.yml`.
- To preview locally: `python -m http.server 8000`, then open http://127.0.0.1:8000.

See `CLAUDE.md` for structure and editing rules.
